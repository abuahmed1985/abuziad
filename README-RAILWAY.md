# النشر على Railway — دبلوم السياحة والفندقة (معهد طيبة)

نسخة كاملة من الموقع (16 مقرراً، 168 درساً، 3,328 سؤالاً) مجهّزة للنشر على
Railway بدلاً من Render. Railway ينشر مباشرة من مستودع GitHub ويعيد النشر
**تلقائياً** عند كل رفع جديد — لا حاجة لزر Manual Deploy.

> ملاحظة صادقة: Railway يعطي رصيد تجربة 5 دولار عند إنشاء الحساب، ثم تُحسب
> التكلفة حسب الاستخدام (خدمة بهذا الحجم نحو 5–10 دولار شهرياً تقريباً بعد
> انتهاء الرصيد). ليس مجانياً للأبد مثل خطة Render المجانية، لكن النشر
> أسهل بكثير.

## 1) ارفع الملفات إلى GitHub (كما كنت تفعل)

ارفع كل ملفات هذا المجلد **مسطّحة في جذر المستودع** (استبدال للقديم):
`server.js` و `seed.js` و `package.json` و `package-lock.json` و
`content-full.js` و `questions-full.js` و `booking-full.js` و
`Amiri-Regular.ttf` و `Amiri-Bold.ttf` و `NotoSansArabic-Regular.ttf` و
`NotoSansArabic-Bold.ttf` و `taiba-logo.jpg` و `tvtc-logo.png` و
`index.html` و `app.js` و `styles.css` (الثلاثة الأخيرة من داخل `public/`) و
`railway.json` (الجديد — لا تحذف `render.yaml` إن أردت الاحتفاظ بنسخة Render).

## 2) أنشئ المشروع في Railway

1. ادخل railway.app وسجّل بحساب GitHub نفسه (`abuahmed1985`).
2. **New Project ← Deploy from GitHub repo** ← اختر مستودع الموقع.
3. Railway سيتعرّف على Node تلقائياً ويبدأ البناء (`npm install` ثم `node server.js`).

## 3) متغيرات البيئة (Variables)

من صفحة الخدمة ← **Variables** ← أضف:

| المتغير | القيمة |
|---|---|
| `DB_PATH` | `/data/taiba.db` |
| `ADMIN_PASSWORD` | كلمة مرور المدير (اخترها أنت) |
| `ACADEMIC_PASSWORD` | كلمة مرور الأكاديمي |
| `TRAINER_PASSWORD` | كلمة مرور المدربة |
| `SESSION_SECRET` | أي نص عشوائي طويل (مثال: `taiba-2026-secret-xyz`) |

إن تركت كلمات مرور الموظفين فارغة، يولّد الخادم كلمات عشوائية تطبع **مرة
واحدة** في السجلات تحت `[FIRST BOOT]` — انسخها من **Deployments ← View Logs**.

## 4) القرص الدائم (مهم — حتى لا تضيع البيانات)

من صفحة الخدمة ← **Settings ← Volumes ← New Volume**:
- **Mount Path:** `/data`
- الحجم: 1 GB يكفي.

بدون القرص، تُفقد الحسابات والملفات المرفوعة عند كل إعادة نشر.

## 5) الرابط العام

من صفحة الخدمة ← **Settings ← Networking ← Generate Domain** — سيعطيك رابطاً
مثل `https://taiba-xxxx.up.railway.app`. افتحه وستظهر الصفحة الرئيسية.

## 6) إعادة النشر

كلما رفعت ملفات جديدة إلى GitHub، يعيد Railway النشر **تلقائياً** خلال
دقائق — لا زر يدوي. تابع الحالة من تبويب **Deployments**.

## تحذيران

1. **البذر يعمل فقط على قاعدة بيانات فارغة** — إن نشرت نسخة سابقة على نفس
   القرص، فلن يظهر المحتوى الحقيقي/البنك إلا بعد حذف قاعدة البيانات من
   القرص وإعادة النشر.
2. **لا تعيد استيراد البنك الكامل من لوحة التحكم بعد أول إقلاع أبداً** —
   الاستيراد يُضيف فوق الموجود فيتضاعف البنك.

## فحص سريع بعد النشر

افتح `https://<رابطك>/api/health` — يجب أن ترى:
`{"ok":true,"courses":16,"questions":3328}`

ثم سجّل الدخول بحساب مدربة (trainer) وتأكد من ظهور تبويب **لوحة التحكم**
في الأعلى، ومنه تستطيع إضافة حسابات جديدة (قسم «إضافة حساب جديد»).
